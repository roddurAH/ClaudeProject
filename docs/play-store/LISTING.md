## Data safety form

**Overview**

| Question | Answer |
|---|---|
| Does your app collect or share any of the required user data types? | Yes |
| Is all of the user data collected by your app encrypted in transit? | Yes (HTTPS only; release builds refuse plain http) |
| Which methods of account creation does your app support? | Username/other + password (phone number + PIN) |
| Do you provide a way for users to request that their data is deleted? | Yes |

**Data types** (everything below: *Collected* = yes, *Shared* = **no**, *Processed ephemerally* = no)

| Category → type | Why it is collected | Required or optional | Purposes to tick |
|---|---|---|---|
| Personal info → **Name** | Account; shown to the expert answering | Optional (only with an account) | App functionality, Account management |
| Personal info → **Phone number** | Login; expert may call back | Optional (only with an account) | App functionality, Account management |
| Location → **Approximate location** | The district the user picks (no GPS); used for weather, nearest market and alerts, and saved in the profile | Optional | App functionality |
| Photos and videos → **Photos** | Photo attached to an expert question or sent to the AI doctor | Optional | App functionality |
| App activity → **Other user-generated content** | Question text sent to experts or to the AI doctor | Optional | App functionality |

Not collected: precise location, contacts, email (app users), financial info, health, messages, audio, files, calendar, app interactions/analytics, crash logs, diagnostics, device or other IDs. The PIN is only stored hashed and is a credential, not a Data safety data type. Weather is fetched by the server from Open-Meteo with the district's coordinates only, so no user data is shared.

**AI doctor:** AI doctor photos and text are processed by Anthropic (Claude) **on our behalf as a service provider**, which Play does not count as "sharing", so keep *Shared = no*. Voice questions are turned into text by the phone's own speech service and the app sends only text, so do **not** declare *Audio*. The app asks for the microphone permission (`RECORD_AUDIO`) only when the user taps 🎤.
